# Wega browser icon

The **Emerald Globe** icon (a green glass globe with a luminous mint orbit ring) is
the source for every app and web icon.

## Provenance and license

The Emerald Globe icon was created for Wega by the project author with AI
image-generation assistance. It is released under the Mozilla Public License 2.0
together with the rest of the project (see `LICENSE` and `NOTICE` in the
repository root). It does not reuse artwork from Firefox, Servo or other browsers.

## Files

`browser-icon-source.png` (1254 × 1254, transparent PNG) is the original artwork.

- `browser-icon.png`: 1024 px master export.
- `browser-icon-256.png`: embedded native window and sidebar icon.
- `BrowserIcon.icns`: macOS 16–1024 px / Retina exports.
- `docker/viewer/favicon.png`: 64 px web icon.
- `docker/viewer/apple-touch-icon.png`: 180 px web icon.

Exports use macOS `sips` and `iconutil` and preserve the source design and
transparency. The default **Wega · Emerald Glass** theme uses emerald surfaces
and mint accents matching this icon.
