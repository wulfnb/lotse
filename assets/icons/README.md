# Lotse browser icon

The user selected the attached **green glass globe with a luminous mint orbit ring**. This exact artwork is the source for every app and web icon.

Source attachment: `exec-c08c1379-b0c3-4aeb-9587-314414d44fe2.png` (1254 × 1254, transparent PNG). `browser-icon-source.png` is a byte-for-byte copy.

- `browser-icon.png`: 1024 px master export.
- `browser-icon-256.png`: embedded native window and sidebar icon.
- `BrowserIcon.icns`: macOS 16–1024 px / Retina exports.
- `docker/viewer/favicon.png`: 64 px web icon.
- `docker/viewer/apple-touch-icon.png`: 180 px web icon.

Exports use macOS `sips` and `iconutil`, preserving the supplied design and transparency. No new image was generated. The default **Lotse · Emerald Glass** theme uses emerald surfaces and mint accents matching this icon.
